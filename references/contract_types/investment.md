# 投资协议专项审核清单
# Investment Agreement Specialized Checklist

---

## 一、交易结构 / Transaction Structure

### 必查项目

- [ ] **投资金额** - 总金额明确
- [ ] **投资方式** - 增资/股权转让/可转债
- [ ] **估值** - 投前估值/投后估值
- [ ] **持股比例** - 投资后各方持股
- [ ] **股权类型** - 普通股/优先股
- [ ] **交割安排** - 分期投资的时间表

### 风险提示

| 风险 | 等级 | 检查要点 |
|------|------|----------|
| 估值计算错误 | 🔴 | 核实投前/投后估值一致性 |
| 股权比例不一致 | 🔴 | 与工商登记核对 |
| 支付条件不明 | 🟡 | 明确交割先决条件 |

---

## 二、先决条件 / Conditions Precedent

### 常见先决条件

- [ ] **尽职调查完成** - DD满意确认
- [ ] **公司决议** - 股东会/董事会批准
- [ ] **政府批准** - 如需外资审批/反垄断申报
- [ ] **第三方同意** - 现有股东放弃优先权
- [ ] **法律意见书** - 目标公司合规确认
- [ ] **交易文件签署** - 全套协议签署
- [ ] **无重大不利变化** - MAC条款

---

## 三、陈述与保证 / Representations & Warranties

### 目标公司/创始人陈述保证

- [ ] 公司依法设立并有效存续
- [ ] 股权结构真实准确
- [ ] 已披露全部重大合同
- [ ] 无未披露负债
- [ ] 知识产权权属清晰
- [ ] 无重大诉讼仲裁
- [ ] 税务合规
- [ ] 劳动合规
- [ ] 无关联交易（或已披露）
- [ ] 资产负债表真实

### 投资方陈述保证

- [ ] 有权进行投资
- [ ] 资金来源合法
- [ ] 非竞争对手（如适用）

---

## 四、投资人权利 / Investor Rights

### 必查项目

- [ ] **董事会席位** - 委派董事的权利
- [ ] **观察员权利** - 列席董事会
- [ ] **信息权** - 财务报告获取
- [ ] **检查权** - 审计和检查权
- [ ] **重大事项知情权** - 及时通知
- [ ] **优先认购权** - 后续融资优先权
- [ ] **反稀释保护** - 价格保护
- [ ] **共同出售权** - Tag-along
- [ ] **优先清算权** - Liquidation Preference

---

## 五、公司治理 / Governance

### 保护性条款（一票否决）

需投资人同意的重大事项：
- [ ] 修改章程
- [ ] 增减注册资本
- [ ] 发行新股/期权
- [ ] 合并分立解散
- [ ] 重大资产处置
- [ ] 关联交易
- [ ] 变更主营业务
- [ ] 对外担保/借款
- [ ] 利润分配
- [ ] 高管任命

---

## 六、退出机制 / Exit Mechanisms

### 必查项目

- [ ] **IPO条款** - 上市义务和时间表
- [ ] **回购条款** - 回购触发条件和价格
- [ ] **对赌条款** - 业绩承诺和补偿
- [ ] **随售权** - Drag-along权利
- [ ] **清算优先权** - 清算分配顺序

### 对赌条款审查

| 审查项 | 检查要点 |
|--------|----------|
| 业绩指标 | 是否明确可量化 |
| 补偿方式 | 现金/股权/回购 |
| 补偿主体 | 公司/创始人/两者 |
| 触发条件 | 是否合理可实现 |
| 上限设置 | 补偿是否有上限 |

> ⚠️ **注意**：根据最高法院《九民纪要》，与目标公司对赌可能因损害债权人利益而被认定无效或不可执行。建议优先与创始人股东对赌。

---

## 七、限制性条款 / Restrictive Covenants

### 创始人限制

- [ ] **全职投入** - 全职经营公司
- [ ] **竞业禁止** - 不得从事竞争业务
- [ ] **股权锁定** - 股权转让限制
- [ ] **知识产权转让** - 转让个人IP给公司

---

## 八、违约与赔偿 / Breach & Indemnification

### 必查项目

- [ ] **违约情形** - 违约定义
- [ ] **赔偿范围** - 直接损失/间接损失
- [ ] **赔偿上限** - 是否有Cap
- [ ] **赔偿程序** - 通知和抗辩程序
- [ ] **时效限制** - 索赔时限

---

## 风险等级速查表

| 条款类别 | 缺失风险 | 优先级 |
|----------|----------|--------|
| 投资金额和估值 | 🔴 | 最高 |
| 陈述与保证 | 🔴 | 最高 |
| 投资人保护条款 | 🔴 | 最高 |
| 退出机制 | 🔴 | 最高 |
| 先决条件 | 🟡 | 高 |
| 公司治理 | 🟡 | 高 |
| 赔偿条款 | 🟡 | 中 |

---

*适用法律：《公司法》《民法典》《九民纪要》*
