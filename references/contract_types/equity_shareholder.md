# 股权/股东协议专项审核清单
# Equity/Shareholder Agreement Specialized Checklist

---

## 一、股权结构与持股 / Equity Structure & Shareholding

### 必查项目 (Must Check)

- [ ] **股权比例明确** - 各方持股比例是否清晰无歧义
- [ ] **股权类型** - 普通股/优先股/限制性股权区分是否明确
- [ ] **认缴与实缴** - 出资方式、金额、时间是否明确
- [ ] **出资证明** - 是否约定出资证明文件
- [ ] **股东名册** - 是否约定股东名册更新程序
- [ ] **代持安排** - 如有代持，是否有明确的代持协议
- [ ] **股权激励池** - 如有预留，比例和授予规则是否明确

### 风险提示

| 风险 | 等级 | 检查要点 |
|------|------|----------|
| 股权比例不明确导致控制权争议 | 🔴 | 确保有明确的持股比例表 |
| 出资瑕疵导致股权不完整 | 🔴 | 检查出资验资证明 |
| 代持关系不清导致权属争议 | 🔴 | 代持协议需单独签署 |
| 股权激励稀释创始人股权 | 🟡 | 明确激励池上限和授予条件 |

## 二、股权转让限制 / Transfer Restrictions

### 必备条款 (Required Clauses)

- [ ] **一般禁止转让条款** - 未经同意不得转让
- [ ] **优先购买权 (ROFR)** - 同等条件下的优先权
- [ ] **共同出售权 (Tag-Along)** - 小股东跟随出售权
- [ ] **强制随售权 (Drag-Along)** - 大股东强制出售权
- [ ] **允许转让的例外** - 关联方转让等
- [ ] **转让价格机制** - 估值方法或定价公式
- [ ] **锁定期 (Lock-up)** - 创始人/关键人锁定期限

### 标准条款参考

```
第X条 股权转让限制

1. 一般限制：未经其他股东[一致/过半数]书面同意，任何股东不得转让其持有的公司股权。

2. 优先购买权：如一方拟向第三方转让股权，应先书面通知其他股东，其他股东在收到通知后[30]日内有权以同等条件优先购买。

3. 共同出售权：如任一股东向第三方转让股权，其他股东有权按比例参与该等转让。

4. 强制随售权：如持有公司[X]%以上表决权的股东同意向第三方出售公司全部或主要资产/股权，其他股东应按相同条件参与出售。

5. 转让限制期：创始人股东在公司成立后[X]年内不得转让其持有的公司股权，但向其关联方转让或经全体股东一致同意除外。
```

### 法律依据
- 《公司法》第71-72条（有限责任公司股权转让）
- 《公司法》第142条（股份有限公司股份转让限制）

## 三、公司治理 / Corporate Governance

### 董事会相关 (Board Matters)

- [ ] **董事会组成** - 人数、各方委派名额
- [ ] **董事任免程序** - 提名、选举、罢免程序
- [ ] **董事会会议** - 召集程序、通知时限、频率
- [ ] **法定人数 (Quorum)** - 最低出席人数要求
- [ ] **投票权** - 每位董事票数、特殊事项表决权
- [ ] **董事会决议事项** - 一般事项 vs 重大事项
- [ ] **观察员权利** - 列席权但无投票权

### 股东会相关 (Shareholders Meeting)

- [ ] **股东会职权** - 明确授权事项范围
- [ ] **会议召集** - 谁有权召集、程序
- [ ] **表决方式** - 按持股比例 vs 按人头
- [ ] **决议门槛** - 一般决议 vs 特别决议
- [ ] **股东知情权** - 查阅权、质询权

### 保护性条款/一票否决权 (Protective Provisions/Veto Rights)

需要特别多数或一致同意的事项：

- [ ] 修改公司章程
- [ ] 变更注册资本
- [ ] 增发或回购股权
- [ ] 重大资产处置
- [ ] 合并、分立、解散
- [ ] 变更主营业务
- [ ] 关联交易超过[X]万元
- [ ] 对外担保
- [ ] 利润分配方案
- [ ] 高管任命与薪酬

## 四、信息权与审计权 / Information Rights

### 必查项目

- [ ] **财务报表** - 月度/季度/年度报告要求
- [ ] **预算与商业计划** - 年度预算审批
- [ ] **审计权** - 指定审计师、审计范围
- [ ] **检查权** - 查阅账簿和记录的权利
- [ ] **通知义务** - 重大事件通知时限
- [ ] **保密义务** - 信息接收方的保密责任

### 标准条款参考

```
第X条 信息权

1. 公司应向各股东提供以下财务信息：
   (a) 月度：未经审计的财务报表，于次月[15]日前提供；
   (b) 季度：季度经营报告，于季度结束后[30]日内提供；
   (c) 年度：经审计的年度财务报表，于年度结束后[90]日内提供。

2. 股东有权查阅公司股东会会议记录、董事会会议决议、财务会计报告等文件。

3. 持有公司[X]%以上股权的股东有权指定会计师事务所对公司财务进行审计，费用由[公司/请求方]承担。
```

## 五、退出机制 / Exit Mechanisms

### IPO相关条款

- [ ] **IPO义务** - 推动上市的义务和时间表
- [ ] **合格IPO定义** - 估值、融资额门槛
- [ ] **上市前重组** - 红筹架构、VIE安排
- [ ] **锁定期** - IPO后限售期

### 并购退出

- [ ] **出售程序** - 谁有权启动出售
- [ ] **估值方法** - 第三方估值、比较法
- [ ] **同意门槛** - 出售需要的同意比例
- [ ] **收益分配** - 清算优先权顺序

### 回购与赎回

- [ ] **回购权** - 触发条件、价格
- [ ] **赎回权** - 投资人要求公司回购的权利
- [ ] **对赌条款** - 业绩承诺与补偿机制

### 清算优先权

- [ ] **优先顺序** - 各轮投资人的清算顺序
- [ ] **参与分配** - 优先返还后是否继续参与
- [ ] **Cap限制** - 回报倍数上限

## 六、反稀释保护 / Anti-Dilution Protection

### 常见类型

- [ ] **完全棘轮 (Full Ratchet)** - 按低价轮价格调整
- [ ] **加权平均 (Weighted Average)** - 考虑融资规模调整
- [ ] **宽基 vs 窄基** - 计算基数范围
- [ ] **豁免情形** - 员工激励、战略投资等

### 标准条款参考

```
第X条 反稀释保护

如公司以低于本轮投资价格发行新股权（"降价融资"），则本轮投资人持有的股权应按以下公式调整：

调整后价格 = [(原价格 × 原股数) + (新价格 × 新股数)] / (原股数 + 新股数)

以下情形不触发反稀释调整：
(a) 员工股权激励计划下发行的股权；
(b) 经[X]%投资人同意的战略融资；
(c) 因股权分割、合并导致的调整。
```

## 七、竞业与不竞争 / Non-Compete & Non-Solicitation

### 创始人竞业限制

- [ ] **限制期间** - 在职期间 + 离职后[X]年
- [ ] **地域范围** - 全球/中国/特定地区
- [ ] **行业范围** - 与公司业务相同或类似
- [ ] **竞业补偿** - 离职后限制期间的补偿

### 不挖角条款

- [ ] **员工不挖角** - 禁止招揽公司员工
- [ ] **客户不挖角** - 禁止招揽公司客户
- [ ] **期限** - 限制期限

### 法律合规提示
> ⚠️ 根据《劳动合同法》第24条，竞业限制期限不得超过2年。对于非劳动关系的股东竞业限制，可约定更长期限，但应确保合理性。

## 八、僵局与争议解决 / Deadlock & Dispute Resolution

### 僵局解决机制

- [ ] **升级协商** - 高层管理人员/创始人协商
- [ ] **调解** - 第三方调解程序
- [ ] **买卖安排 (Shotgun Clause)** - 一方出价，另一方选择买或卖
- [ ] **强制出售** - 持续僵局后的出售安排
- [ ] **解散** - 最终解散程序

### 争议解决条款

- [ ] **协商前置** - 友好协商期限
- [ ] **仲裁 vs 诉讼** - 选择争议解决方式
- [ ] **仲裁机构** - CIETAC/BAC/HKIAC等
- [ ] **仲裁地点** - 北京/上海/香港等
- [ ] **仲裁语言** - 中文/英文
- [ ] **仲裁员人数** - 独任/三人
- [ ] **费用承担** - 败诉方承担

## 九、离职股东处理 / Leaver Provisions

### Good Leaver vs Bad Leaver

| 类型 | 定义 | 股权处理 |
|------|------|----------|
| Good Leaver | 正常离职、退休、死亡、工伤 | 按公允价值回购 |
| Bad Leaver | 主动辞职、被解雇（过错）、违反竞业 | 按成本价/低价回购 |

### 股权成熟 (Vesting)

- [ ] **成熟期限** - 通常4年
- [ ] **悬崖期 (Cliff)** - 通常1年
- [ ] **成熟方式** - 按月/按季度/按年
- [ ] **加速成熟** - 控制权变更时加速
