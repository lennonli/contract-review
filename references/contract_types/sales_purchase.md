# 买卖/采购合同专项审核清单
# Sales/Purchase Contract Specialized Checklist

---

## 一、标的物 / Subject Matter

### 必查项目

- [ ] **名称规格** - 产品名称、型号、规格
- [ ] **数量** - 具体数量和计量单位
- [ ] **质量标准** - 国标/行标/企标/样品
- [ ] **包装要求** - 包装方式和标准
- [ ] **技术参数** - 详细技术指标（附件）

### 风险提示

| 风险 | 等级 | 检查要点 |
|------|------|----------|
| 规格不明确 | 🔴 | 需有详细产品清单 |
| 质量标准缺失 | 🔴 | 明确验收依据 |
| 数量计算争议 | 🟡 | 明确计量方法 |

---

## 二、价格与支付 / Price & Payment

### 必查项目

- [ ] **单价和总价** - 金额明确
- [ ] **价格构成** - 是否含税、运费
- [ ] **货币** - 币种明确
- [ ] **支付方式** - 电汇/信用证/承兑
- [ ] **支付时间** - 预付/货到付款/账期
- [ ] **价格调整** - 长期合同的调价机制

### 支付方式风险对比

| 支付方式 | 卖方风险 | 买方风险 |
|----------|----------|----------|
| 全额预付 | 低 | 高 |
| 货到付款 | 高 | 低 |
| 信用证 | 低 | 中 |
| 30天账期 | 中 | 低 |

---

## 三、交付 / Delivery

### 必查项目

- [ ] **交付时间** - 具体日期或期限
- [ ] **交付地点** - 明确地址
- [ ] **交付方式** - 送货/自提/物流
- [ ] **运输责任** - 运费和风险承担
- [ ] **交付凭证** - 签收单/提单
- [ ] **分批交付** - 分批安排（如有）

### 贸易术语（如适用国际贸易）

| 术语 | 风险转移点 | 费用承担 |
|------|-----------|----------|
| EXW | 卖方处所 | 买方全部 |
| FOB | 装运港船上 | 卖方至装船 |
| CIF | 装运港船上 | 卖方含运费保险 |
| DDP | 买方处所 | 卖方全部 |

---

## 四、验收 / Acceptance

### 必查项目

- [ ] **验收标准** - 质量检验依据
- [ ] **验收期限** - 收货后X日内
- [ ] **验收程序** - 检验方法和流程
- [ ] **异议期限** - 发现问题后X日内
- [ ] **第三方检验** - 争议时的处理
- [ ] **验收文件** - 验收单格式

### 法律规定

> 《民法典》第621条：买受人应当在约定的检验期限内将标的物的数量或者质量不符合约定的情形通知出卖人。买受人怠于通知的，视为标的物的数量或者质量符合约定。

---

## 五、质量保证 / Quality Warranty

### 必查项目

- [ ] **质保期限** - 起算点和期限
- [ ] **质保范围** - 保修内容
- [ ] **质保排除** - 不保修情形
- [ ] **维修方式** - 返修/换货/退款
- [ ] **响应时间** - 维修服务时效

### 法定质保

| 产品类型 | 法定质保 | 依据 |
|----------|----------|------|
| 一般商品 | 无强制 | 约定为准 |
| 三包商品 | 7日退/15日换/保修 | 《三包规定》 |
| 建设工程 | 主体50年/防水5年 | 《建设工程质量管理条例》 |

---

## 六、所有权与风险 / Title & Risk

### 必查项目

- [ ] **所有权转移** - 何时转移
- [ ] **风险转移** - 何时转移
- [ ] **所有权保留** - 付清前保留所有权
- [ ] **保险** - 货物保险安排

### 法律规定

> 《民法典》第604条：标的物毁损、灭失的风险，在标的物交付之前由出卖人承担，交付之后由买受人承担。

---

## 七、违约责任 / Breach of Contract

### 必查项目

- [ ] **延迟交付** - 违约金或损失赔偿
- [ ] **质量不合格** - 退换货、违约金
- [ ] **延迟付款** - 逾期利息
- [ ] **解除权** - 根本违约的解除
- [ ] **责任上限** - 是否有Cap

### 违约金合理性

> 《民法典》第585条：约定的违约金过分高于造成的损失的，人民法院或者仲裁机构可以根据当事人的请求予以适当减少。一般认为超过实际损失30%为"过分高于"。

---

## 八、知识产权 / Intellectual Property

### 必查项目（如涉及定制产品）

- [ ] **IP归属** - 定制产品IP归谁
- [ ] **侵权保证** - 卖方保证不侵权
- [ ] **侵权赔偿** - 第三方索赔处理
- [ ] **模具/工装** - 专用模具归属

---

## 九、保密 / Confidentiality

### 必查项目

- [ ] **价格保密** - 价格信息保密
- [ ] **技术保密** - 图纸规格保密
- [ ] **客户信息** - 客户名单保密

---

## 十、不可抗力 / Force Majeure

### 必查项目

- [ ] **定义** - 不可抗力事件范围
- [ ] **通知义务** - 通知时限和方式
- [ ] **证明文件** - 需提供的证明
- [ ] **后果** - 免责/延期/解除

---

## 风险等级速查表

| 条款类别 | 缺失风险 | 优先级 |
|----------|----------|--------|
| 标的物描述 | 🔴 | 最高 |
| 价格与支付 | 🔴 | 最高 |
| 质量标准 | 🔴 | 最高 |
| 交付条款 | 🔴 | 高 |
| 验收条款 | 🟡 | 高 |
| 质保条款 | 🟡 | 中 |
| 违约责任 | 🟡 | 中 |
| 风险转移 | 🟡 | 中 |

---

*适用法律：《民法典》第595-647条（买卖合同）*
