# 服务/咨询协议专项审核清单
# Service/Consulting Agreement Specialized Checklist

---

## 一、服务范围 / Scope of Services

### 必查项目

- [ ] **服务描述** - 具体服务内容是否清晰
- [ ] **交付物** - 可交付成果清单
- [ ] **服务标准** - 质量标准或SLA
- [ ] **排除范围** - 不包含的服务
- [ ] **变更程序** - 服务范围变更流程

### 风险提示

| 风险 | 等级 | 检查要点 |
|------|------|----------|
| 范围不明确导致争议 | 🔴 | 需有详细的工作说明书(SOW) |
| 无验收标准 | 🟡 | 明确验收标准和程序 |

---

## 二、服务期限与里程碑 / Term & Milestones

### 必查项目

- [ ] **服务期限** - 起止日期
- [ ] **里程碑** - 关键节点和时间表
- [ ] **延期处理** - 延期的后果和补救
- [ ] **续约条款** - 续约条件

---

## 三、费用与支付 / Fees & Payment

### 必查项目

- [ ] **费用结构** - 固定费用/按时计费/按成果付费
- [ ] **费用金额** - 明确金额或费率
- [ ] **支付条件** - 触发支付的条件
- [ ] **支付时间** - 付款期限
- [ ] **发票要求** - 发票类型和开具时间
- [ ] **费用调整** - 年度调价机制
- [ ] **额外费用** - 差旅费、材料费等
- [ ] **逾期付款** - 滞纳金或利息

### 标准条款参考

```
第X条 服务费用

1. 服务费用：本项目服务费总计人民币[X]元（大写）。

2. 支付方式：
   - 合同签订后[X]日内，支付[X]%作为预付款；
   - [里程碑1]完成并验收后，支付[X]%；
   - 全部服务完成并最终验收后，支付剩余[X]%。

3. 付款期限：委托方应在收到服务方发票后[30]日内完成付款。

4. 逾期付款：逾期支付的，按未付金额每日[0.05]%支付滞纳金。
```

---

## 四、知识产权 / Intellectual Property

### 必查项目

- [ ] **服务成果归属** - 交付物知识产权归属
- [ ] **背景IP** - 各方既有IP权利
- [ ] **许可授权** - 使用服务方工具/方法论的授权
- [ ] **第三方IP** - 使用第三方IP的授权和责任
- [ ] **道德权利** - 署名权等

### 归属模式

| 模式 | 描述 | 适用场景 |
|------|------|----------|
| 委托方所有 | 成果完全归委托方 | 定制开发 |
| 服务方所有+许可 | 服务方保留所有权，授权委托方使用 | 标准化服务 |
| 共有 | 双方共同拥有 | 联合开发 |

### 常见问题 ⚠️

| 问题 | 风险等级 |
|------|----------|
| 成果归属不明确 | 🔴 |
| 未区分背景IP和新创IP | 🟡 |
| 缺少使用许可范围 | 🟡 |

---

## 五、保密条款 / Confidentiality

### 必查项目

- [ ] **保密信息定义** - 范围是否明确
- [ ] **保密义务** - 双向保密
- [ ] **保密期限** - 合理期限（通常2-5年）
- [ ] **例外情形** - 公开信息、法律要求等
- [ ] **返还/销毁** - 合同结束后的处理

---

## 六、陈述与保证 / Representations & Warranties

### 服务方陈述保证

- [ ] 有权提供服务
- [ ] 服务符合约定标准
- [ ] 不侵犯第三方权利
- [ ] 人员具备相应资质

### 委托方陈述保证

- [ ] 有权签订合同
- [ ] 提供信息真实准确
- [ ] 配合义务

---

## 七、责任限制 / Limitation of Liability

### 必查项目

- [ ] **责任上限** - 通常为合同金额的[X]倍
- [ ] **排除间接损失** - 利润损失、商誉损失等
- [ ] **例外情形** - 故意、重大过失、IP侵权等不受限制
- [ ] **保险要求** - 职业责任保险

### 标准条款参考

```
第X条 责任限制

1. 除本协议另有规定外，任何一方因本协议产生的或与本协议相关的责任总额，不超过本协议项下已支付服务费用的[1]倍。

2. 任何一方均不对另一方承担任何间接损失、附带损失、特殊损失或惩罚性赔偿，包括但不限于利润损失、数据丢失、商誉损失。

3. 上述责任限制不适用于以下情形：
   (a) 故意或重大过失；
   (b) 侵犯知识产权；
   (c) 违反保密义务；
   (d) 人身伤害。
```

---

## 八、合同解除 / Termination

### 必查项目

- [ ] **便利终止** - 是否允许无因终止
- [ ] **终止通知期** - 提前通知要求
- [ ] **违约终止** - 终止事由
- [ ] **终止后果** - 费用结算、工作移交
- [ ] **存续条款** - 终止后继续有效的条款

---

## 九、独立承包商 / Independent Contractor

### 必查项目

- [ ] **关系性质** - 明确非雇佣关系
- [ ] **税务责任** - 各自承担税务
- [ ] **社保责任** - 服务方自行负责
- [ ] **无代理权** - 不得代表对方

---

## 十、争议解决 / Dispute Resolution

### 必查项目

- [ ] **协商前置** - 友好协商期限
- [ ] **争议解决方式** - 仲裁或诉讼
- [ ] **管辖地** - 仲裁地/法院
- [ ] **费用承担** - 争议解决费用

---

## 风险等级速查表

| 条款类别 | 缺失风险 | 优先级 |
|----------|----------|--------|
| 服务范围 | 🔴 | 最高 |
| 费用与支付 | 🔴 | 最高 |
| 知识产权归属 | 🔴 | 最高 |
| 责任限制 | 🟡 | 高 |
| 保密条款 | 🟡 | 高 |
| 验收标准 | 🟡 | 中 |
| 解除条款 | 🟡 | 中 |

---

*适用法律：《民法典》合同编（委托合同、承揽合同）*
