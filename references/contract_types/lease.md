# 租赁协议专项审核清单
# Lease Agreement Specialized Checklist

---

## 一、租赁标的 / Leased Property

### 必查项目

- [ ] **物业描述** - 地址、面积、用途是否明确
- [ ] **权属证明** - 出租方是否有权出租（产权证/授权）
- [ ] **物业现状** - 交付时的状态描述
- [ ] **附属设施** - 设备、家具清单
- [ ] **共用部分** - 公共区域使用权

### 风险提示

| 风险 | 等级 | 检查要点 |
|------|------|----------|
| 无权出租 | 🔴 | 核实产权证或转租授权 |
| 面积争议 | 🟡 | 建筑面积vs使用面积需明确 |
| 用途限制 | 🟡 | 检查房产用途是否匹配 |

---

## 二、租赁期限 / Lease Term

### 法定限制

| 规定 | 内容 | 法律依据 |
|------|------|----------|
| 最长期限 | 不得超过20年 | 《民法典》第705条 |
| 超期效力 | 超过部分无效 | 同上 |
| 续租 | 可约定续租条件 | 《民法典》第734条 |

### 必查项目

- [ ] **起止日期** - 租期起止明确
- [ ] **提前终止** - 终止条件和通知期
- [ ] **续租条款** - 续租权、优先承租权
- [ ] **免租期** - 装修免租期（如有）

---

## 三、租金与费用 / Rent & Expenses

### 必查项目

- [ ] **租金金额** - 金额、币种明确
- [ ] **支付方式** - 月付/季付/年付
- [ ] **支付时间** - 每期支付截止日
- [ ] **租金调整** - 调价机制（年度涨幅上限）
- [ ] **押金** - 金额、退还条件
- [ ] **物业费** - 由谁承担
- [ ] **水电费** - 计费方式、由谁承担
- [ ] **税费** - 租赁税费由谁承担

### 标准条款参考

```
第X条 租金及支付

1. 租金：每月租金为人民币[X]元（大写：[X]元整）。

2. 支付方式：承租方应于每[月/季度]首日前[5]个工作日内，将当[月/季]租金支付至出租方指定账户。

3. 押金：承租方应于本合同签订时支付押金人民币[X]元，租赁期满且承租方无违约行为及欠费的，出租方应于交还物业后[15]日内无息退还。

4. 租金调整：自第[2]年起，每年租金在上一年基础上上调不超过[5]%。
```

---

## 四、使用与维护 / Use & Maintenance

### 必查项目

- [ ] **使用用途** - 限定用途或禁止用途
- [ ] **装修改造** - 是否需要事先同意
- [ ] **装修归属** - 租期届满装修物归属
- [ ] **日常维护** - 维护责任划分
- [ ] **重大维修** - 结构性维修责任
- [ ] **检查权** - 出租方检查权及通知要求

### 维护责任划分建议

| 项目 | 通常责任方 |
|------|-----------|
| 结构性维修（屋顶、墙体） | 出租方 |
| 日常维护（灯泡、龙头） | 承租方 |
| 设备故障（空调、电梯） | 约定/出租方 |
| 装修损坏 | 承租方 |

---

## 五、转租与转让 / Sublease & Assignment

### 必查项目

- [ ] **转租限制** - 是否禁止或需同意
- [ ] **转让限制** - 租赁权转让条件
- [ ] **违规转租后果** - 解除权

### 法律规定

> 《民法典》第716条：承租人经出租人同意，可以将租赁物转租给第三人。承租人未经出租人同意转租的，出租人可以解除合同。

---

## 六、合同解除 / Termination

### 必查项目

- [ ] **出租方解除权** - 解除事由
- [ ] **承租方解除权** - 解除事由
- [ ] **通知期限** - 提前通知要求
- [ ] **违约解除后果** - 违约金、损害赔偿
- [ ] **物业返还** - 返还程序和标准

### 常见解除事由

| 方 | 解除事由 |
|----|----------|
| 出租方 | 欠租达[X]日、擅自转租、擅自改变用途、严重损坏物业 |
| 承租方 | 物业存在安全隐患、出租方不履行维修义务、权属争议影响使用 |

---

## 七、其他重要条款 / Other Key Provisions

### 必查项目

- [ ] **优先购买权** - 出售时承租方是否有优先权
- [ ] **抵押告知** - 物业是否存在抵押
- [ ] **保险** - 财产保险、责任保险
- [ ] **不可抗力** - 租金减免、解除权
- [ ] **争议解决** - 仲裁或诉讼

---

## 风险等级速查表

| 条款类别 | 缺失风险 | 优先级 |
|----------|----------|--------|
| 权属证明 | 🔴 | 最高 |
| 租金条款 | 🔴 | 最高 |
| 租期明确 | 🔴 | 高 |
| 押金退还 | 🟡 | 高 |
| 维护责任 | 🟡 | 中 |
| 转租限制 | 🟡 | 中 |
| 解除条款 | 🟡 | 中 |

---

*适用法律：《民法典》第703-734条（租赁合同）*
