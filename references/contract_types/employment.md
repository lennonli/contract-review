# 劳动合同专项审核清单
# Employment Contract Specialized Checklist

---

## 一、合同基本信息 / Basic Information

### 必查项目 (Must Check)

- [ ] **用人单位信息** - 全称、地址、法定代表人
- [ ] **劳动者信息** - 姓名、身份证号、住址
- [ ] **合同类型** - 固定期限/无固定期限/以完成一定工作任务为期限
- [ ] **合同期限** - 起止日期明确
- [ ] **签订日期** - 是否在用工之日起一个月内签订
- [ ] **签字盖章** - 双方签字盖章完整

### 法律强制要求 (Legal Requirements)

根据《劳动合同法》第17条，劳动合同必须具备以下条款：

| 必备条款 | 检查状态 | 风险等级 |
|----------|----------|----------|
| 用人单位信息 | [ ] | 🔴 |
| 劳动者信息 | [ ] | 🔴 |
| 合同期限 | [ ] | 🔴 |
| 工作内容和工作地点 | [ ] | 🔴 |
| 工作时间和休息休假 | [ ] | 🔴 |
| 劳动报酬 | [ ] | 🔴 |
| 社会保险 | [ ] | 🔴 |
| 劳动保护、劳动条件和职业危害防护 | [ ] | 🟡 |

## 二、试用期条款 / Probation Period

### 法定限制

| 合同期限 | 试用期上限 | 法律依据 |
|----------|-----------|----------|
| 3个月以下 | 不得约定 | 《劳动合同法》第19条 |
| 3个月-1年 | 1个月 | 《劳动合同法》第19条 |
| 1年-3年 | 2个月 | 《劳动合同法》第19条 |
| 3年以上/无固定 | 6个月 | 《劳动合同法》第19条 |

### 必查项目

- [ ] **试用期期限** - 是否符合法定上限
- [ ] **试用期工资** - 不低于约定工资的80%，且不低于当地最低工资
- [ ] **试用期社保** - 试用期内应依法缴纳社保
- [ ] **试用期解除** - 解除条件是否明确、合法
- [ ] **仅约定试用期** - 不得仅约定试用期（视为正式期限）

### 常见违法情形 ⚠️

| 违法情形 | 法律后果 |
|----------|----------|
| 试用期超过法定期限 | 超过部分按正式期限，并支付赔偿金 |
| 试用期工资过低 | 补足差额 |
| 多次约定试用期 | 同一用人单位只能约定一次试用期 |
| 未缴社保 | 补缴+可能的行政处罚 |

---

## 三、工作内容与地点 / Job Duties & Location

### 必查项目

- [ ] **岗位名称** - 是否明确
- [ ] **职责描述** - 主要工作内容是否清晰
- [ ] **工作地点** - 具体地址或合理范围
- [ ] **工作地点变更** - 变更程序是否约定
- [ ] **岗位调整** - 调岗条件和程序

### 风险提示

> ⚠️ 工作地点约定过于宽泛（如"全国"）可能导致用人单位滥用调岗权，损害劳动者利益。建议约定具体城市或区域，并明确变更需协商一致。

---

## 四、工作时间与休息休假 / Working Hours & Leave

### 工时制度审查

| 工时制度 | 适用条件 | 加班规定 |
|----------|----------|----------|
| 标准工时 | 默认适用 | 日8小时、周40小时，超出为加班 |
| 综合计算工时 | 需审批 | 周期内平均不超标准 |
| 不定时工时 | 需审批，限特定岗位 | 一般无加班费 |

### 必查项目

- [ ] **工时制度类型** - 是否明确
- [ ] **特殊工时审批** - 如采用非标准工时，是否有审批文件
- [ ] **工作时间** - 每日起止时间
- [ ] **休息日** - 每周休息安排
- [ ] **法定节假日** - 是否依法休假
- [ ] **带薪年休假** - 天数是否符合法定标准
- [ ] **其他假期** - 病假、婚假、产假、丧假等

### 法定年休假标准

| 累计工作年限 | 年休假天数 | 法律依据 |
|-------------|-----------|----------|
| 1年-10年 | 5天 | 《职工带薪年休假条例》第3条 |
| 10年-20年 | 10天 | 同上 |
| 20年以上 | 15天 | 同上 |

## 五、劳动报酬 / Compensation

### 必查项目

- [ ] **基本工资** - 金额明确、货币单位清晰
- [ ] **最低工资** - 不低于当地最低工资标准
- [ ] **工资构成** - 基本工资、绩效、补贴等结构
- [ ] **支付周期** - 按月支付，具体日期
- [ ] **支付方式** - 银行转账/现金
- [ ] **加班工资** - 计算基数和标准
- [ ] **年终奖/奖金** - 发放条件和计算方式
- [ ] **工资调整** - 调薪机制

### 加班工资标准

| 加班类型 | 工资倍数 | 法律依据 |
|----------|----------|----------|
| 工作日加班 | 150% | 《劳动法》第44条 |
| 休息日加班（不能调休） | 200% | 同上 |
| 法定节假日加班 | 300% | 同上 |

### 常见问题 ⚠️

| 问题 | 风险等级 | 说明 |
|------|----------|------|
| 工资约定不明确 | 🔴 | 仅写"面议"无效 |
| 加班费计算基数过低 | 🟡 | 不得低于最低工资 |
| 绩效扣减无标准 | 🟡 | 需有明确考核制度 |
| 年终奖约定模糊 | 🟡 | 建议明确发放条件 |

---

## 六、社会保险与福利 / Social Insurance & Benefits

### 法定社保 (五险)

| 险种 | 用人单位义务 | 法律依据 |
|------|-------------|----------|
| 养老保险 | 强制缴纳 | 《社会保险法》第10条 |
| 医疗保险 | 强制缴纳 | 《社会保险法》第23条 |
| 失业保险 | 强制缴纳 | 《社会保险法》第44条 |
| 工伤保险 | 强制缴纳（单位全额） | 《社会保险法》第33条 |
| 生育保险 | 强制缴纳 | 《社会保险法》第53条 |

### 住房公积金

- [ ] **缴纳义务** - 是否依法缴纳
- [ ] **缴纳比例** - 是否符合当地规定

### 必查项目

- [ ] **社保缴纳** - 是否明确约定依法缴纳
- [ ] **不得放弃** - 不得约定劳动者放弃社保
- [ ] **其他福利** - 补充医疗、商业保险等

> ⚠️ **重要提醒**：任何"自愿放弃社保"的约定均无效，用人单位仍需依法缴纳。

---

## 七、保密与竞业限制 / Confidentiality & Non-Compete

### 保密条款审查

- [ ] **保密范围** - 商业秘密定义是否明确
- [ ] **保密期限** - 合理期限
- [ ] **保密义务** - 具体义务内容
- [ ] **违约责任** - 违反保密的后果

### 竞业限制条款审查

| 审查项目 | 法定要求 | 检查状态 |
|----------|----------|----------|
| 适用对象 | 仅限高管、高技、其他负有保密义务者 | [ ] |
| 限制期限 | 不超过2年 | [ ] |
| 经济补偿 | 必须约定，离职后按月支付 | [ ] |
| 补偿标准 | 不低于离职前12个月平均工资的30%，且不低于当地最低工资 | [ ] |
| 限制范围 | 地域、行业应合理 | [ ] |
| 违约金 | 可约定，但应合理 | [ ] |

### 法律依据
- 《劳动合同法》第23-24条
- 《最高人民法院关于审理劳动争议案件适用法律问题的解释(一)》第36-40条

### 常见问题 ⚠️

| 问题 | 后果 |
|------|------|
| 未约定竞业补偿 | 劳动者可主张按工资30%支付 |
| 补偿过低 | 可能被认定显失公平 |
| 限制期限超过2年 | 超过部分无效 |
| 对一般员工适用 | 可能被认定无效 |

## 八、培训与服务期 / Training & Service Period

### 必查项目

- [ ] **培训类型** - 是否为专项技术培训
- [ ] **培训费用** - 费用明细和凭证
- [ ] **服务期限** - 合理期限
- [ ] **违约金** - 不得超过培训费用
- [ ] **违约金递减** - 是否按已服务期限递减

### 法律要点

> 根据《劳动合同法》第22条：
> - 仅"专项技术培训"可约定服务期
> - 日常培训、入职培训不得约定服务期
> - 违约金不得超过用人单位实际支出的培训费用
> - 违约金应按已履行服务期限递减

### 违法情形 ⚠️

| 违法情形 | 法律后果 |
|----------|----------|
| 非专项培训约定服务期 | 服务期约定无效 |
| 违约金超过培训费 | 超出部分无效 |
| 未提供培训费凭证 | 难以主张违约金 |

---

## 九、合同变更与解除 / Amendment & Termination

### 合同变更

- [ ] **变更程序** - 应协商一致，书面形式
- [ ] **单方调岗** - 条件是否合法合理
- [ ] **降薪情形** - 是否符合法律规定

### 劳动者解除权

| 解除情形 | 通知要求 | 法律依据 |
|----------|----------|----------|
| 提前通知解除 | 提前30日书面通知 | 《劳动合同法》第37条 |
| 试用期解除 | 提前3日通知 | 同上 |
| 即时解除（单位过错） | 无需通知 | 《劳动合同法》第38条 |

### 用人单位解除权

| 解除情形 | 条件 | 法律依据 |
|----------|------|----------|
| 过错解除 | 严重违纪、不胜任等 | 《劳动合同法》第39条 |
| 无过错解除 | 医疗期满、不胜任培训/调岗后仍不胜任、客观情况重大变化 | 《劳动合同法》第40条 |
| 经济性裁员 | 20人以上或10%以上 | 《劳动合同法》第41条 |

### 不得解除情形

根据《劳动合同法》第42条，以下情形用人单位不得解除：
- [ ] 从事职业病危害作业未离岗健康检查
- [ ] 疑似职业病在诊断或医学观察期间
- [ ] 患职业病或工伤丧失劳动能力
- [ ] 患病或非因工负伤在医疗期内
- [ ] 女职工孕期、产期、哺乳期
- [ ] 在本单位连续工作满15年且距退休不足5年

## 十、经济补偿与赔偿 / Severance & Damages

### 经济补偿标准

| 工作年限 | 补偿标准 | 备注 |
|----------|----------|------|
| 不满6个月 | 0.5个月工资 | |
| 6个月-1年 | 1个月工资 | |
| 每满1年 | 1个月工资 | N个月 |
| 工资超3倍社平 | 按3倍封顶，最多12年 | 高薪员工限制 |

### 违法解除赔偿金

- 赔偿金 = 经济补偿 × 2（2N）
- 适用于用人单位违法解除的情形

### 必查项目

- [ ] **经济补偿计算基数** - 离职前12个月平均工资
- [ ] **补偿年限** - 工作年限计算
- [ ] **支付时限** - 办理工作交接时支付

## 十一、争议解决 / Dispute Resolution

### 法定程序

1. **协商** - 双方协商解决
2. **调解** - 企业调解委员会/基层调解组织
3. **仲裁** - 劳动争议仲裁委员会（前置程序）
4. **诉讼** - 对仲裁裁决不服可起诉

### 必查项目

- [ ] **争议解决条款** - 是否符合法定程序
- [ ] **仲裁时效** - 1年（从知道或应当知道之日起）
- [ ] **管辖** - 用人单位所在地或劳动合同履行地

> ⚠️ **注意**：劳动争议必须先经仲裁，不能直接诉讼。约定绕过仲裁程序的条款无效。
