# 保密协议(NDA)专项审核清单
# Non-Disclosure Agreement Specialized Checklist

---

## 一、协议类型 / Agreement Type

### 类型识别

| 类型 | 描述 | 适用场景 |
|------|------|----------|
| 单向NDA | 仅一方披露信息 | 投资尽调、供应商评估 |
| 双向NDA | 双方互相披露 | 商务合作、技术交流 |
| 多方NDA | 三方或更多方 | 联合开发、多方合作 |

### 必查项目

- [ ] **协议类型** - 单向还是双向
- [ ] **披露方/接收方** - 各方角色明确
- [ ] **披露目的** - 信息用途限定

---

## 二、保密信息定义 / Definition of Confidential Information

### 必查项目

- [ ] **定义范围** - 是否涵盖所需保护的信息类型
- [ ] **标记要求** - 是否需要标注"保密"
- [ ] **口头信息** - 口头披露的处理方式
- [ ] **信息形式** - 书面、电子、口头、视觉

### 标准定义参考

```
"保密信息"是指一方（"披露方"）向另一方（"接收方"）披露的与披露方业务相关的所有非公开信息，无论以何种形式或媒介披露，包括但不限于：

(a) 技术信息：发明、专利、专有技术、软件、算法、设计、图纸等；
(b) 商业信息：客户名单、供应商信息、定价策略、营销计划、财务数据等；
(c) 其他信息：员工信息、合同条款、商业秘密等。

口头或视觉披露的信息，如在披露时或披露后[10]日内以书面形式确认为保密信息的，亦构成保密信息。
```

---

## 三、保密信息的例外 / Exclusions

### 标准例外

- [ ] **公开信息** - 非因接收方违约而公开的信息
- [ ] **事先知悉** - 接收方在披露前已合法知悉
- [ ] **独立开发** - 接收方独立开发的信息
- [ ] **第三方来源** - 从无保密义务的第三方合法获得
- [ ] **书面同意** - 披露方书面同意披露

### 标准条款参考

```
以下信息不属于保密信息：

(a) 在披露时已为公众所知，或此后非因接收方违反本协议而成为公开信息；
(b) 接收方能够以书面证据证明在披露前已合法拥有；
(c) 接收方从无保密义务的第三方合法获得；
(d) 接收方能够以书面证据证明系独立开发，未使用或参考披露方的保密信息。
```

---

## 四、保密义务 / Confidentiality Obligations

### 必查项目

- [ ] **保密标准** - 注意义务程度
- [ ] **使用限制** - 仅限约定目的使用
- [ ] **披露限制** - 知悉必要原则
- [ ] **人员管理** - 员工/顾问保密义务
- [ ] **安全措施** - 保护措施要求

### 保密标准选项

| 标准 | 描述 | 适用场景 |
|------|------|----------|
| 同等保护 | 与保护自身保密信息相同的程度 | 一般商业 |
| 合理注意 | 合理的保密措施 | 标准条款 |
| 最高注意 | 最高程度的保密措施 | 高度敏感 |

---

## 五、允许披露 / Permitted Disclosures

### 必查项目

- [ ] **法律强制披露** - 法院命令、政府要求
- [ ] **通知义务** - 强制披露前通知披露方
- [ ] **最小范围** - 仅披露必要范围
- [ ] **保护措施** - 寻求保护令等

### 标准条款参考

```
如接收方被法律、法规或政府机关要求披露保密信息，接收方应：

(a) 在法律允许的范围内，立即书面通知披露方；
(b) 仅披露法律要求的最小范围内的信息；
(c) 应披露方的合理要求，协助披露方寻求适当的保护措施；
(d) 根据上述要求披露的信息仍受本协议约束。
```

---

## 六、期限 / Term

### 必查项目

- [ ] **协议期限** - 协议有效期
- [ ] **保密期限** - 保密义务持续时间
- [ ] **商业秘密** - 商业秘密无期限保护

### 期限建议

| 信息类型 | 建议保密期限 |
|----------|-------------|
| 一般商业信息 | 2-3年 |
| 技术信息 | 3-5年 |
| 商业秘密 | 信息保持秘密状态期间 |
| 个人信息 | 法律规定期限 |

---

## 七、返还与销毁 / Return & Destruction

### 必查项目

- [ ] **触发条件** - 协议终止或披露方要求
- [ ] **返还义务** - 返还所有载体
- [ ] **销毁义务** - 无法返还的应销毁
- [ ] **销毁证明** - 书面确认
- [ ] **例外保留** - 法律要求保留的副本

---

## 八、无权利授予 / No Rights Granted

### 必查项目

- [ ] **无许可授予** - 不构成IP许可
- [ ] **无义务披露** - 无强制披露义务
- [ ] **所有权保留** - 保密信息所有权不转移
- [ ] **无合作义务** - 不构成合作承诺

---

## 九、救济措施 / Remedies

### 必查项目

- [ ] **禁令救济** - 不可弥补损害的声明
- [ ] **损害赔偿** - 违约赔偿
- [ ] **合理费用** - 律师费等

### 标准条款参考

```
双方确认，保密信息的未经授权披露或使用将对披露方造成不可弥补的损害，金钱赔偿不足以弥补该等损害。因此，披露方有权寻求禁令或其他衡平法救济，而无需证明实际损害或提供担保。该等救济不排除披露方寻求其他法律救济的权利。
```

## 十、其他条款 / Miscellaneous

### 必查项目

- [ ] **整体协议** - 取代此前约定
- [ ] **修改** - 书面形式
- [ ] **转让** - 是否可转让
- [ ] **可分割性** - 部分无效不影响整体
- [ ] **准据法** - 适用法律
- [ ] **争议解决** - 管辖/仲裁

## 常见问题与风险

| 问题 | 风险等级 | 建议 |
|------|----------|------|
| 保密信息定义过窄 | 🔴 | 扩大定义范围 |
| 无期限保密义务 | 🟡 | 约定合理期限 |
| 缺少例外条款 | 🟡 | 增加标准例外 |
| 无强制披露程序 | 🟡 | 增加通知和最小披露要求 |
| 缺少禁令救济 | 🟡 | 增加衡平法救济条款 |

---

## 风险等级速查表

| 条款类别 | 缺失风险 | 优先级 |
|----------|----------|--------|
| 保密信息定义 | 🔴 | 最高 |
| 保密义务 | 🔴 | 最高 |
| 使用限制 | 🔴 | 高 |
| 例外条款 | 🟡 | 高 |
| 保密期限 | 🟡 | 中 |
| 返还销毁 | 🟡 | 中 |
| 救济措施 | 🟡 | 中 |
