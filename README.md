# contract-review

中国执业律师业务 skill：合同审查、Word 修订模式（tracked changes）合同修订、法律文件起草。

## 安装

将本仓库克隆到本机 skills 目录（目录已存在时先备份替换），确保 `SKILL.md` 位于目录根部，然后重启会话生效：

```bash
git clone https://github.com/lennonli/contract-review.git ~/.agents/skills/contract-review
```

> 已存在旧版本的，先执行 `mv ~/.agents/skills/contract-review ~/.agents/skills/contract-review.bak` 再克隆。

## 功能

### 合同审查工作流
1. 先概述协议主要内容（交易背景、权利义务、付款交付验收、违约、管辖等逐项说明）；
2. 按核心/中等/低风险等级逐条审查，每项风险给出条款位置、风险说明、影响及可直接替换的修改文本；
3. 补充缺失条款及完善建议（覆盖定义、验收、付款、保密、知识产权、数据合规、责任上限、不可抗力、争议解决等 28 类常见缺失）；
4. 同步进行文字、逻辑、格式、序号校对；
5. 生成可直接发送客户的简短汇报（整体风险等级、关键风险、最重要修改点、是否适合签署）。

### 文档修订模式
- 严格最小必要修改，保留原文结构、编号、格式与表格，新增文字继承原格式；
- 修订人统一为"锦天城-李成"；
- 修订及批注时间戳按交付日前 1–2 个工作日、以 20–200 秒随机间隔递增分布，且不早于收到文件的时间；
- 无法实现修订模式的，提供清洁版修订文本 + 修改对照表；
- 命名规则：`原名称-ABL-修订日期-V1`，后续修订 V2、V3 递增。

### 法律文件起草要求
- 起草前识别文件类型、客户立场、相对方、交易背景、关键商业条款与风险分配；
- 条款编号按"第一条"、1.1、1.1.1 分级，"第 X 条"仅写标题；
- 命名规则：`合同名称-文件生成日期-ABL-V1`；
- 签署页单独成页，以分页符与正文分隔。

### 附带脚本（scripts/）
| 脚本 | 用途 |
| --- | --- |
| `read_full_docx.py` | 完整读取 docx 段落与表格文本 |
| `revise_contract.py` | 以 Word 原生修订痕迹执行查找替换式修订（`--author` 指定修订人） |
| `compare_versions.py` | 比对两版合同生成差异报告 |

## 适用范围

中华人民共和国大陆法域的中文合同与法律文件。skill 不预置任何具体客户名称；委托方身份由使用者在会话中指定。
